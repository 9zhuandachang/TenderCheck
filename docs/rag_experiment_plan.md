- S604 的 50 条需求已完成 BM25、混合检索、混合加重排序、预测类别策略加重排序四组实验，候选池 50，返回前 5。
- 增加文件哈希＋页码＋原文的参考证据计分，支持必要证据组、等价位置、表格必要文本片段及跨段落证据。

## 后续顺序

1. 补齐扫描证书、跨页业绩、人员身份关联、技术方案等必要证据组，人工核对后冻结参考集。
2. 在独立开发集排查投标有效期混入施工工期、历史合同占据当前项目证据位置、多证据缺项等问题。保留当前测试结果，避免在同一测试集反复调参。
3. 扩展独立项目，按八类要求、文本/表格/扫描及单/多证据报告覆盖率。充分标注所有候选后再增加 Precision、nDCG、无证据识别指标。
4. LLM 与规则接口已于 2026-10-20 接入实际段落输入，见 [无台账推理流程](evidence_reasoning.md)。待配置密钥后实测提取正确率、证据忠实性，再用人工结论标签评估规则结果。
5. 测固定上下文预算及预热后的耗时中位数/P95、显存峰值和失败率，建立阶段验收门槛。

新旧评测的样本分母、判分条件和重排序候选预算不同，不能直接比较百分比并推断模型进退。2026-10-20 清理后，旧台账代码及字段代理评测已退出当前版本；历史代码可通过 Git 记录恢复。原始文件、成功 OCR 缓存和旧索引未改写。

完整输出保存在忽略目录 `SystemCode/reports/rag_experiments/`；公开文件只保留脱敏汇总。模型加载或重排序失败时标记失败，不将回退计作正式成绩。
