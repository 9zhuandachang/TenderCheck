# Project Report — TenderCheck

This folder contains the project report and technical documentation for **TenderCheck — Neuro-Symbolic Intelligent Bid Compliance Review System**:

- `TenderCheck_System_Implementation_EN.docx`: Full technical documentation of the 6-step neuro-symbolic architecture, model training, Parent-Child Hybrid RAG, slot extraction & anti-hallucination grounding, deterministic symbolic rule engine (`R01`–`R09`), and end-to-end evaluation results.
- `TenderCheck_Installation_and_User_Guide_EN.docx`: Step-by-step installation guide, Google Drive model & dataset setup, and annotated user walkthrough of the Streamlit Review Workspace (`Overview`, `Review Workspace`, `Remediation`, and `Report & Export`).
